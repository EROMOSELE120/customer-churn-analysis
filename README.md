# Customer Churn Prediction Using Machine Learning

## Project Overview

This project uses the Telco Customer Churn dataset to explore customer behaviour and develop machine learning models that predict whether a customer is likely to leave a service.

The project was completed as part of the NexAfrica Internship Program, under the Machine Learning track.

## Project Stages

- **Week 1:** Data preparation and cleaning.
- **Week 2:** Exploratory data analysis (EDA) and feature engineering.
- **Week 3:** Machine learning model development and comparison.

## Machine Learning Models

Three classification models were developed and compared:

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

The models were evaluated using accuracy, precision, recall, F1-score, and ROC-AUC.

In the initial comparison, Logistic Regression achieved 80.3% accuracy and a ROC-AUC of 0.842.
